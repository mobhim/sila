نظام صلة الفندقي
================

الملفات
- index.html      هيكل الصفحة
- css/style.css   الأنماط والثيم
- js/app.js       منطق النظام كاملاً
- img/            صور الغرف وخلفية الشاشة

التشغيل
افتح index.html في المتصفح مباشرة، أو ارفع المجلد كما هو على أي استضافة ثابتة.
الخطوط تُحمَّل من Google Fonts، فتحتاج اتصالاً بالإنترنت لتظهر كما في التصميم.

ملاحظات
- البيانات تجريبية ومحفوظة في المتصفح (localStorage).
- ميزات الذكاء الاصطناعي عبر Claude (فهم الطلبات، التسعير، الشات) تعمل فقط داخل صفحة Claude المنشورة.
  خارجها يعمل النظام بالقواعد المكتوبة في الكود. لتفعيلها على موقعكم اربطوا الدوال التي تستخدم ask في js/app.js بواجهة API من خادمكم.
- ملف عرض الفعاليات PDF ينزل هنا بتنزيل المتصفح العادي.
