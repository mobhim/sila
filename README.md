# صلة · Sila

مساعد فندقي يكمل وصول النزيل برقم الهوية أو رقم الجوال، لا يصدر المفتاح قبل جاهزية الغرفة، ويحل مشاكل ما بعد الدفع داخل حدود يضبطها الفندق. معه مخطِّط فعاليات يصدر عرضاً تنفيذياً كاملاً.

> **محاكاة:** لا يُخصم مبلغ، لا تُرسل رسائل، ولا يُفتح باب. البيانات تُحفظ في المتصفح فقط.

## الصفحات

| الصفحة | الملف | لمن |
|---|---|---|
| موقع صلة 2.1 (كيف تعمل، النموذج الحي، القدرات، الصلاحيات، الإدارة، الفعاليات) | `index.html` | النزيل والمستثمر: شاشة الوصول الحيّة، حدود المساعد، الغرف، مخطِّط الفعاليات |
| معالم المدن | `landmarks.html` | صفحة مستقلة: صور حقيقية لمعالم خمس مدن بحركة مرتبطة بالتمرير |
| لوحة الإدارة | `admin.html` | موظفو الفندق: بيانات النزلاء والحجوزات، لوحة الغرف، الموافقات والبلاغات، التسعير، الصلاحيات، السجل |

الصفحتان منفصلتان: بيانات العملاء لا تظهر في موقع النزيل. تتزامنان حيّاً داخل المتصفح نفسه، فافتح كل واحدة في نافذة وجرّب: غيّر حالة غرفة أو وافق على طلب من لوحة الإدارة وستتحدّث شاشة النزيل فوراً.

> لوحة الإدارة **غير محمية بتسجيل دخول** في نسخة المحاكاة. أضف مصادقة حقيقية قبل أي تشغيل فعلي.

## التشغيل محلياً

يتطلب Node.js 20.12 أو أحدث.

```bash
npm install
```

```bash
npm start
```

ثم افتح `http://localhost:3000` للموقع و `http://localhost:3000/admin` للإدارة.

## ربط الذكاء الاصطناعي (Claude)

بدون مفتاح يعمل الموقع بقواعده المكتوبة. لتفعيل الفهم عبر Claude:

1. انسخ `.env.example` إلى `.env`.
2. ضع مفتاحك في السطر `ANTHROPIC_API_KEY=` (تحصل عليه من console.anthropic.com).
3. أعد تشغيل `npm start`. يظهر في الطرفية `AI: on`.

المفتاح يبقى على الخادم فقط: المتصفح يرسل اسم المهمة والنص إلى `/api/ask`، والخادم يملك التعليمات والحدود (`lib/sila-ai.js`).

| متغير | الغرض | الافتراضي |
|---|---|---|
| `ANTHROPIC_API_KEY` | مفتاح Claude | — |
| `SILA_MODEL` | النموذج | `claude-opus-5-5` |
| `SILA_RATE_PER_MIN` | حد الطلبات لكل عنوان في الدقيقة | 30 |
| `SILA_DAILY_CAP` | حد الطلبات اليومي | 3000 |
| `SILA_ALLOWED_ORIGINS` | نطاقات يُسمح لها باستدعاء الـ API من موقع آخر | لا شيء |
| `SILA_MOCK=1` | ردود ثابتة لتجربة الربط بلا مفتاح | معطّل |

## الرفع إلى GitHub

1. ثبّت [Git](https://git-scm.com/download/win).
2. أنشئ مستودعاً فارغاً على [github.com/new](https://github.com/new).
3. شغّل `github-setup.ps1` (زر الفأرة الأيمن ← Run with PowerShell) والصق رابط المستودع.

الملف يهيّئ المستودع، يتأكد أن `.env` غير مرفوع، ثم يرفع. شغّله مرة أخرى بعد أي تعديل لرفع التحديث.

## النشر على Vercel

1. من [vercel.com/new](https://vercel.com/new) اختر مستودع GitHub.
2. أضف `ANTHROPIC_API_KEY` في Environment Variables.
3. انشر. الملف `vercel.json` يضبط دالة `/api/ask` والعناوين.

## بنية الملفات

```
index.html      موقع النزيل
landmarks.html  صفحة معالم المدن
admin.html      لوحة الإدارة
style.css       الأنماط للصفحتين
experience.css  طبقة تجربة صلة 2.1 (الأقسام الجديدة والحركة) فوق style.css
experience.js   حركة صلة 2.1 وتفاعلاتها (قائمة الجوال، تبويبا المحاكاة، أمثلة الصلاحيات، تلميح المحادثة)
media/          لقطات النموذج الأولي (عربي وإنجليزي)، صورة المشاركة og.jpg، وأيقونات الأجهزة
vendor/gsap/    مكتبة GSAP لصفحة المعالم (مستضافة محلياً)
manifest.webmanifest  تعريف الموقع عند إضافته للشاشة الرئيسية
app.js          المنطق كاملاً (المصدر)
app.min.js      نسخة مصغّرة من app.js تستخدمها الصفحات؛ أعد توليدها بعد أي تعديل: npm run build
                (الإقامة، التسعير، الفعاليات، المحادثة، المعالم، المزامنة)
i18n.en.js      النصوص الإنجليزية
server.js       خادم محلي
api/ask.js      دالة Vercel
lib/sila-ai.js  مهام Claude الخمس وحدودها
logo.svg        الشعار
landmarks/      صور المعالم (ويكيميديا كومنز، المصادر والتراخيص في أسفل قسم المعالم)
PRODUCT.md      حقيقة المنتج
DESIGN.md       النظام البصري
```

## بعد تعديل app.js

الصفحات تحمّل `app.min.js`. بعد أي تعديل على `app.js` شغّل:

```bash
npm install
npm run build
```
